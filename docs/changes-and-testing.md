## v7 炼狱、无限挑战与职业平衡

新增两种开局模式：**炼狱**打完第5轮最终BOSS通关；**无限挑战**每轮结束继续下一轮，直到队伍失败，没有预设通关轮数。原简单/普通（含默认）仍为3轮，困难/极难仍为4轮。二转仍在第3轮建筑开放后办理，全部三转仍从第4轮开始、消耗15木材。

两个新模式均以250%敌方基础生命、0初始金币和1初始木材开始；三围随机成长上限额外降低0.5。每完成一轮，新生敌人的生命按基础值再增30%并加100，攻击力再增12%；魔抗最多65%。这些增长从新生单位计算，不把上轮结果重复相乘。普通房最多13只敌人，避免出生点越界。新模式单次BOSS存档积分随轮次增长、最高25分。

第五轮起新模式使用4种新小怪和2种新BOSS，无限模式后续轮换组合。新敌人接入实际行动预告与战斗施法：

| 敌人 | 专属行为 |
|---|---|
| 炼狱铁卫 | 为敌方群体加临时护甲，同类护盾不叠加 |
| 烬火咒师 | 对全体存活英雄施放火雨 |
| 裂魂猎手 | 攻击生命比例最低英雄并削蓝 |
| 血泉祭司 | 为敌方群体恢复生命 |
| 熔炉暴君 | 群体震荡并获得临时护甲 |
| 虚空摄政 | 群体伤害、削蓝，按实际扣血汲取生命且封顶 |

新敌人中仅裂魂猎手、虚空摄政属于亡灵；其余四种不吃反亡灵加成。使用地图已有模型，新增独立单位数据和技能行为。

**多人难度重评**：原来主要增加怪物数量，3人以上只额外加一次生命档，攻击没有人数倍率。现在每房间按仍在玩的真人英雄人数快照，在原难度、数量和BOSS房规则上，每额外1人再增加小怪生命20%、BOSS生命45%、攻击力10%。6人额外倍率分别为2倍、3.25倍、1.5倍，并非全部最终倍率。倒地但仍在局的玩家继续计入；离开者下一房排除。固定数值的旧伤害技能不额外重复乘攻击倍率，奖励不按人数另加。

**一转重新转职**：已一转、尚未二转时，可到原泉水一转建筑选择其他普通职业或随机，每次10存档积分。保留等级、既得升级收益、装备、当前生命和魔法（上限降低时封顶）；清理旧职业技能/被动，返还已学职业技能点，隐藏职业成长率和三相修炼不叠加。当前资格按清理职业修炼后的基础属性检查；已一转重选不重复要求5级。普通同职业直选不扣分；随机仍10%隐藏，抽到同职业也算有效付费抽取。牧师已领取的同等级学习赠药不能重复领取。二转及三转后不提供重转。

**牧师伤害调整**：圣光球、审判之光的基础伤害统一乘0.8，主/次目标对亡灵均改为额外25%，替代原2倍/3倍。群体恢复、护甲、回蓝、修炼和三转治疗保留；僧侣物理分支不因本次反亡灵调整额外削弱。原对象提示、动态预估及转职面板说明同步更新。

## v5 火法与快捷键修复

二转火法的火球和炎爆术原来共用底层施法命令，炎爆术三个等级均没有独立命令，且按钮位置重叠。这会在炎爆术可用时出现点击火球却施放炎爆的情况。

本版为炎爆术三个等级设置独立命令并分开按钮：火球仍为 **Q**，炎爆术仍为 **E**；不改这两个技能的伤害、资源消耗、冷却或每回合次数。三转的五类主动技能（含隐藏三转）统一改为 **Z**，位于独立的第二行第三格，保留原职业 E 技能；技能说明和转职面板同步更新。
