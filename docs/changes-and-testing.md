# AI爬塔 v6：三转消耗15木材

## v6 三转费用

所有16条普通三转路线与隐藏三转均消耗 **15木材**。仍要求已完成二转、进入第4轮，并在原二转建筑办理；二转出现时机和原通关轮数保持原样。

转职面板显示费用与当前木材，确认按钮标明15木材。每次确认都会重新检查当前余额和其他条件：不足15时不转职、不扣款；刚好15时完成三转后剩余0；三转成功后的重复点击不会再次扣款。费用从发起玩家自己的木材中扣除，一转、二转不收取此费用。

所有技能、属性奖励、被动和成长强度保持v5数值。玩家可选择前中期把木材兑换属性，或攒15木材用于三转。三转成功提示同步明确扣费及Z快捷键。

建议实测：14木材拒绝、15木材恰好完成、20木材完成后剩5；界面打开后先在别处花掉木材，再点击确认应重新拦截；双人各自扣费；连续确认不会重复扣款。

## v5 火法与快捷键修复

二转火法的火球和炎爆术原来共用底层施法命令，炎爆术三个等级均没有独立命令，且按钮位置重叠。这会在炎爆术可用时出现点击火球却施放炎爆的情况。

本版为炎爆术三个等级设置独立命令并分开按钮：火球仍为 **Q**，炎爆术仍为 **E**；不改这两个技能的伤害、资源消耗、冷却或每回合次数。三转的五类主动技能（含隐藏三转）统一改为 **Z**，位于独立的第二行第三格，保留原职业 E 技能；技能说明和转职面板同步更新。

对象与脚本检查覆盖炎爆三个等级、冷却就绪/未就绪两种状态，以及17条三转路线的714组保留技能对比，确认新增Z不与原技能的快捷键、按钮位置和施法命令冲突。原图1075条SLK记录完整保留，仅炎爆原记录新增三个命令字段；原技能二进制文件保持原样。

仍需KK实测：学会炎爆后在其可用时按Q或点击火球，应只施放火球且不消耗炎爆次数；按E可单独施放炎爆；三转后按Z施放觉醒技能，Q/E继续对应原技能。

## v3 轮次与入口

一转仍使用泉水爬塔房间的原一转建筑。两座原二转建筑保留原位置与出现时机，点击任意一座打开同一个独立进阶面板。普通的一转英雄看到自己的二转分支，已二转英雄看到对应三转；隐藏职业只显示自己的进阶。

## 一转与随机职业

普通一转保留原等级、基础属性门槛和职业转换逻辑。
随机一转要求：英雄等级至少5级，基础力量、敏捷、智力各至少10。不计算装备和临时增益。抽取一次即转职，不能重抽。
- 90%：8种普通职业均等概率（每种11.25%）。随机入口统一使用三围各10的门槛，不另外要求兽族步兵的12力量。
- 10%：「万象行者」，唯一的隐藏一转入口。

隐藏进阶：万象行者 → 万象织法者 → 万象天枢。
二转要求：原二转建筑已出现，等级15、基础三围各20。三转要求：已完成隐藏二转，进入第4轮后在泉水房间办理，消耗15木材。
普通二转、三转面板不显示隐藏路线；隐藏玩家只显示自己的进阶。

隐藏职业数值：
- 三相打击（Q）：1行动点、0魔法。单体物理伤害基值，一转为攻击力×0.60 + 三围总和×0.45；二转为攻击力×0.65 + 三围总和×0.65；三转为攻击力×0.70 + 三围总和×0.80。技能、最终倍率、暴击与目标减伤按原图规则结算。三个阶段使用各自的Q说明，一转不显示后续数值。
- 三相回元（D，一转解锁）：1行动点、2魔法，战斗中每回合一次。恢复自身15+三围总和×0.5点生命，最多为生命上限30%，不超过缺失生命。满血时不消耗资源与使用次数。
- 万象汲取（V，二转解锁）：2行动点、3魔法，战斗中每回合一次。对当前敌人造成三围总和×1.75的法术伤害；按目标实际损失生命的25%恢复自身，最多为自身生命上限15%。未造成掉血不会吸血，超杀部分不算吸血。
- 均衡修炼：一转获得每级力量、敏捷、智力成长各+0.15，不在后续转职重复叠加。
- 三相修炼：可学习的职业被动，每级永久基础三围各+2，最多3级；二转、三转保留已学等级与未用技能点，不重复发放属性。
- 二转追加三围各+3、行动点上限+1。
- 三转追加三围各+5、技能伤害+15%；不再追加行动点或成长。
- 万象共鸣（Z）：2行动点、3魔法，每回合一次；全体当前存活敌人受到三围总和×1.1的法术伤害，计入技能、法伤及最终倍率与目标防御。

## R冥想修复

原图计算了「3 + 智力÷5」却未实际增加魔法；同时地图的智力增加魔法上限。
修改为：
- 战斗中使用，消耗1行动点、0魔法，每回合一次。
- 按施法前智力，真实恢复3 + 智力÷5点魔法，最多补满施法前的魔法上限。
- 本回合临时智力提高30%（向下取整），但不增加魔法上限，也不接受该智力变化附带的当前魔法增加。
- 在技能生效事件结算，不在刚开始引导时发放效果。
- 回合结束、战斗结束、换房间的三处清理都移除临时智力，并保留真实恢复的魔法。
- 技能原始说明与动态数值预览同步更新。

例：施法前智力30，魔法21/40，行动点3。施法后智力39，魔法30/40，行动点2。清除临时智力后智力30，魔法仍30/40。
