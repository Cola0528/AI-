## v2 加载兼容修复

用户反馈：原图在 KK 对战平台可以加载，v1 修改版在读条中途闪退。
排查发现 v1 的 7 个新增技能通过 war3map.w3a 继承 ANcl / Aamk，但原图经过精简的 AbilityData.slk 已没有这两个原始 ID，造成技能对象的基类依赖缺失。

v2 将新增技能直接写入原图已有的 SLK 数据格式，从现存技能行克隆完整记录，并补齐技能说明；原 war3map.w3a 恢复为与原图逐字节相同的内容。另移除 v1 新加的 DzFrameSetEnable 接口依赖，将职业初始化改为单独的短延时回调，并保护界面创建失败时的空句柄。

对象依赖检查保留了 v1 的错误数据作为回归样例：旧数据应检出 7 个缺失基类，v2 应全部通过。上述是已发现并修复的数据兼容缺陷；这里无法启动 KK 客户端，尚不能证明它是闪退的唯一原因，也不能宣称已经通过实机加载。

本版保留 v2 兼容修复。请使用文件名带 **Round4-v3** 的新地图，先在原图能正常运行的同一 KK 客户端里检查能否完整加载，再进行下方玩法验证。

## v3 轮次与入口

一转仍使用泉水爬塔房间的原一转建筑。两座原二转建筑保留原位置与出现时机，点击任意一座打开同一个独立进阶面板。普通的一转英雄看到自己的二转分支，已二转英雄看到对应三转；隐藏职业只显示自己的进阶。

二转建筑在第3轮开始时出现；出现前高级入口隐藏，二转列表和确认操作均不可用。已经二转的英雄可以预览三转条件，从第4轮开始才可确认觉醒。一转建筑仅办理一转。

泉水房间的快捷按钮及自动打开的面板遵守相同规则。独立面板继续展示职业定位、技能、被动与条件，原建筑商品已移除。

原通关轮数保留：简单/普通及默认难度在第3轮结束，困难/极难在第4轮结束。低难度可二转，三转适用于能够进入第4轮的难度。

面板分为「定位 / 条件」「战斗技能」「被动 / 收益」。有多个技能或被动时用上一项、下一项查看；最后点击明确标示职业名的确认按钮。关闭按钮与 Esc 可收起。

## 一转与随机职业

普通一转保留原等级、基础属性门槛和职业转换逻辑。
随机一转要求：英雄等级至少5级，基础力量、敏捷、智力各至少10。不计算装备和临时增益。抽取一次即转职，不能重抽。
- 90%：8种普通职业均等概率（每种11.25%）。随机入口统一使用三围各10的门槛，不另外要求兽族步兵的12力量。
- 10%：「万象行者」，唯一的隐藏一转入口。

隐藏进阶：万象行者 → 万象织法者 → 万象天枢。
二转要求：原二转建筑已出现，等级15、基础三围各20。三转要求：已完成隐藏二转，进入第4轮后在泉水房间办理。
普通二转、三转面板不显示隐藏路线；隐藏玩家只显示自己的进阶。

隐藏职业数值：
- 三相打击（Q）：1行动点、0魔法。单体物理伤害基值，一转为攻击力×0.60 + 三围总和×0.45；二转为攻击力×0.65 + 三围总和×0.65；三转为攻击力×0.70 + 三围总和×0.80。计入技能与最终伤害倍率，另受目标防御影响，不额外掷随机暴击。
- 均衡修炼：一转获得每级力量、敏捷、智力成长各+0.15，不在后续转职重复叠加。
- 三相修炼：可学习的职业被动，每级永久基础三围各+2，最多3级；二转、三转保留已学等级与未用技能点，不重复发放属性。
- 二转追加三围各+3、行动点上限+1。
- 三转追加三围各+5、技能伤害+15%；不再追加行动点或成长。
- 万象共鸣（E）：2行动点、3魔法，每回合一次；全体当前存活敌人受到三围总和×1.1的法术伤害，计入技能、法伤及最终倍率与目标防御。

## 三转

完成前3轮、进入第4轮就解锁三转，无需通关第4轮。按整轮进度判断；前3轮即使走到本轮后面的房间也不能三转。游戏内轮数显示、条件提示与实际确认使用同一轮数。
普通职业三转采用原英雄上的觉醒，保留原单位类型以兼容既有职业判定、技能、修炼、装备与成长；觉醒名称显示在转职面板，原单位名称仍是二转职业。
各职业新增对应觉醒属性、被动与E技能。普通三转不另设等级或属性门槛，需完成二转、人在泉水房间且无待选奖励。
三转每局只能一次。伤害技能不额外附送随机暴击。

## R冥想修复

原图计算了「3 + 智力÷5」却未实际增加魔法；同时地图的智力增加魔法上限。
修改为：
- 战斗中使用，消耗1行动点、0魔法，每回合一次。
- 按施法前智力，真实恢复3 + 智力÷5点魔法，最多补满施法前的魔法上限。
- 本回合临时智力提高30%（向下取整），但不增加魔法上限，也不接受该智力变化附带的当前魔法增加。
- 在技能生效事件结算，不在刚开始引导时发放效果。
- 回合结束、战斗结束、换房间的三处清理都移除临时智力，并保留真实恢复的魔法。
- 技能原始说明与动态数值预览同步更新。

例：施法前智力30，魔法21/40，行动点3。施法后智力39，魔法30/40，行动点2。清除临时智力后智力30，魔法仍30/40。
