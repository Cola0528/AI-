## 本版改动

- **木材抽奖改为能力商人的购买图标**：每次1木，点击购买即抽取。选中商店不再弹出抽奖窗口；连续购买不弹出结果窗打断操作，结果通过简短提示和抽取记录查看。原概率保留。
- **伤害榜更紧凑**：“本场 / 本局”短页签与标题放在同一行，宽度缩小约32%；玩家姓名、伤害和占比按实际玩家颜色显示。大数字使用万/亿等缩写，排序和统计数值保留。
- **记录连续滚动**：最新记录在上，多次结果按行连续列出，鼠标移入内容区后滚轮查看；也可使用上/下按钮与“最新”。保留最近64次抽取，每次十连的10项奖励全部保留。窗口面积缩小约44%。
- **确认窗口缩小**：R技能替换窗面积缩小约59%，技能详情可滚动，费用提示和确认按钮固定可见；升级选择改成两列，面积缩小约47%；难度窗口进一步收紧。
