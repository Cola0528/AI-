## 本版改动

- **矮人狙击手**：显示“子弹 当前/容量”，容量随连狙改造等级变化；空弹红色提示“Q装填”。
- **僧侣 / 金刚禅师**：显示“气 当前/3”，满气绿色提示“已满”；随攻击蓄气、技能消耗、三转充气和战斗重置更新。
- **兽族狂暴步兵**：蓄力重砍被动达到2级后显示“重砍 当前/15”；累计14次时提示“下次+1力”。按实际触发计数。
- **紧凑状态行**：每0.2秒读取自己的实际数值，只有相关职业显示；向上增加一行，准备面板位置与间距保持不变。小游戏及普通职业隐藏此行，F5随状态栏一起收起。
