## 本版改动

- 左下入口统一两列三行：属性详情 / 选择路线、存档 / 遗物、礼包抽奖 / 抽取记录。与状态栏、准备栏和原生底栏留出间距。
- 准备栏按人数调整高度，4～6人时使用两列简短状态；“说明”提供完整队伍名单。出发按钮保留。
- 难度窗口改为两列三行，面积比 v8 缩小约63%；升级选择和R技能替换分别按内容设置大小。
- 指定选路玩家、路线列表、木材抽取、抽取记录和职业窗口重新安排尺寸、按钮与页脚。
- 同时只展示一个主要详情/选择窗口；伤害榜、行动预告和结束回合面板在主要窗口展开时收起。
- 伤害榜高度随人数调整，长名字使用玩家编号，避免挤占伤害数字和说明。
