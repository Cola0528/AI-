# AI爬塔地图修改版 v15

17条三转职业重做：8个专属主动、9个可升级被动。三转费用为 **30木材＋1000金币**。

- **狙击手与弩车**：子弹驱动的单体必中重狙；有方向和宽度的直线贯穿。
- **刺客与职业奖励**：两条刺客路线行动点上限+1，分别获得连斩回点、斩杀回点；其它职业也按玩法区分奖励。
- **三转被动成长**：自动1级，在泉水转职窗口每花1技能点升1级，最高3级；升级被动不再扣木材和金币。
- **三转名字与状态**：设置本英雄的原生名称及称号；扩充紧凑职业计数，保留弹匣、气、重砍显示。
- **双资源扣费**：确认时同时检查木材、金币，任一不足均不扣款；仍是第4轮开放。

包含v14及此前的玩法、界面、中文名、抽奖、背包和公共事件修改。
