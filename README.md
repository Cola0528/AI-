# AI爬塔地图修改版 v16

针对v15进入加载画面前崩溃的兼容性修复：移除两个新增改名接口的强制原生绑定，装载接口清单恢复为v14使用的清单。

- 三转时通过原图已有的Lua桥接检查改名接口；缺失、解析失败或调用报错时跳过改名，转职继续完成。
- 支持接口时仍只修改当前英雄的名称与称号；不支持时，原生经验条/单位栏可能仍显示二转名称，自定义职业界面继续显示三转名。
- 保留v15全部17条三转、8个主动与9个可升级被动、职业奖励、第四轮开放及 **30木材＋1000金币** 费用。
