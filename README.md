## v4 初始成长与礼包抽奖

初始成长改成与存档界面一致的独立面板，显示六项成长数值与评级。保留原免费重置次数，新增「5积分重置」：每次消耗5存档积分，不消耗免费次数，不限次数；确认开始后不能继续重置。积分不足或云档未载入时不会扣款、不会重置。

礼包改成独立的积分抽奖，与存档直接兑换分开：**每抽5积分**，固定概率如下，面板内公开展示。

| 抽取结果 | 每局效果 | 概率 |
|---|---|---:|
| 谢谢惠顾 | 无礼包 | 55% |
| 木材礼包 | 木材+1 | 15% |
| 金币礼包 | 金币+50 | 12% |
| 重随礼包 | 初始成长免费重置次数+3 | 8% |
| 内测礼包 | 金币+50，力量/敏捷/智力各+1 | 4% |
| 预约礼包 | 木材+1，力量/敏捷/智力各+1 | 4% |
| 首充礼包 | 金币+100，力量/敏捷/智力各+1 | 2% |

抽到未拥有礼包则永久解锁，提交平台后从下局起自动应用；原有权益保留。抽到已拥有礼包按重复处理，不重抽、不叠加、不返积分。概率不随拥有数量调整，因此45%礼包结果包括重复，不代表45%获得新礼包。六项全部拥有后停止扣款抽奖。

原存档十项永久成长仍明码标价兑换，价格和限购次数保留。成长付费重置、礼包抽奖使用同一个存档积分余额。

## v4 隐藏职业与伤害说明

随机一转仍是 **10%隐藏、90%普通**，普通的8种职业等概率；已用实际抽取回调遍历概率分支核对。

- 一转新增「三相回元（D）」：按三围总和治疗自己，消耗1行动点、2魔法，每回合一次；治疗最多为生命上限30%。
- 二转新增「万象汲取（V）」：全属性法术伤害，按目标实际掉血吸血，消耗2行动点、3魔法，每回合一次；单次吸血最多为自身生命上限15%。
- 三转保留「万象共鸣（E）」群体法术，继承前两转技能。
- 三相打击（Q）说明只显示当前转职阶段的数值，进阶时替换，不再把二转、三转数值挤在一转说明里。
- 新增伤害技能统一走原图的最终倍率、暴击与减伤结算，修正之前重复应用最终伤害倍率的问题。

## 毒伤参考显示修复

毒伤范围原来用特殊短横线连接上下界。用户反馈的 `450715.5` 与 `450–715.5` 分隔符未显示的情况吻合；现改为明确的 **450 至 715.5**，避免两个数值连成一个大数。上轮实际扣血490与这个范围并不矛盾；当前参考仍根据当前毒层、属性、暴击及脚本魔抗计算，不能用上轮记录代替。

本次只修改范围显示文字，实际毒伤公式、扣血记录与毒层递减保持原样。44项模拟断言覆盖10层、多来源、暴击上下界及历史扣血490；KK字体显示仍需实测。
