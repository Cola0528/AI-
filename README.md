## 本版改动

- **问号事件公共弹窗**：所有玩家收到同一份结果，显示触发者与队友影响；可滚动回看最近512行。关闭只影响自己，左侧“问号事件”按钮可重新打开。事件结果不再刷聊天框。修复全队学习秘籍时，加成全部落到触发者身上的旧问题。
- **满包仍可买药水**：原泉水商店、200金币不变；购买直接增加一次药水次数，不占格、不额外触发原生治疗，助手购买也计入自己的英雄。
- **装备自动转存**：关卡奖励、抽奖圣剑与合成装备优先进入领取背包，英雄满包转助手；两边都满才放到领取单位脚下。保留手动转交操作。
- **修正虚假主动提示**：冰霜权杖、冰霜之剑、埃苏尼之精髓、法术大师手套改为纯被动装备标记；新手法杖、小刀及吞噬类物品的主动操作保留。
- **僧侣重做**：普攻吃全属性并积攒“气”；可把气用于单体输出兼救助低血队友，或全队护甲。三转金刚禅师获得专属“万法归一”：群攻、群体治疗与护甲，并补满气。技能与转职说明同步更新，三转仍需30木材。
- **转职手动打开**：进入、再次进入泉水均不主动弹转职窗；自行点击原按钮或原建筑打开。
