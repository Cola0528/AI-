## 本版改动

- 三转统一改成30木材；仍从第4轮、原二转建筑办理，技能强度保留。
- 修复毒矛学会后缺失的伤害公式，学习提示、三个已学等级及转职预览同步修正。
- 装备商店房的地精商店/能力商人增加独立1木抽取窗口：50%谢谢惠顾，另外50%沿用原十连奖池；窗口公开完整概率。
- 十连抽仍消耗648金币，奖励概率保留；完整结果放入弹窗，“抽取记录”可查看最近64次记录。
- 难度、升级三选一、R技能替换使用新版独立界面，保留F6收起和待选项；初始成长继续使用新版界面。
- 伤害榜增加“本场战斗 / 本局总计”页签，各人独立切换；总计跨房间、轮次保留。
- 主机选择难度后，指定一名在线玩家负责选路；可选队友。该玩家退出时自动交接。
- 单击节点提出目的地，全队可见头顶标识；另有按地图从左到右排列的节点列表，改善点不中的问题。
- 准备窗口新增“出发”，全员完成待选项并准备后，由指定玩家点击进入；不再反复点节点或双击。

伤害榜沿用原统计口径，包含溢出伤害。木材抽取不消耗存档积分，也不写入永久存档。礼包5积分抽奖、成长5积分重置、一转10积分重转继续使用各自入口。
